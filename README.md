# Portfolio — Kolluri David Calvin

A black and white, classic-serif portfolio website. Plain HTML, CSS and JavaScript only, so there is nothing to install or build.

## Files

- `index.html` – all the content
- `style.css` – all the design
- `script.js` – menu, scroll animation, empty-link handling
- `assets/David_Calvin_Resume.pdf` – the resume the "Download Resume" button opens

## Adding your project links later

Open `index.html`, search for `ADD YOUR`, and paste each URL between the quotes of the `href=""` just below the comment:

```html
<a href="https://your-live-project.com" class="link" ...>Live Demo</a>
```

Empty links appear dimmed and do nothing. Once you add a URL, they turn normal on their own.

## Run locally

Double-click `index.html`, or run `python -m http.server 8000` in this folder and open http://localhost:8000
